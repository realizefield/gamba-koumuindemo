# がんばけんぽう だい10しょう「がくもんのじゆう」おんせいだいほん
# VOICEVOX しこくめたんよう

===== いんとろ =====

こんにちは。がんばけんぽう、だい10しょうのてーまは「がくもんのじゆう」です。

このしょうでは、けんぽう23じょうがほしょうするがくもんのじゆうと、だいがくのじちについてまなびます。

とくにじゅうようなはんれいが、とうだいぽぽろじけんです。だいがくないでのがくせいしゅうかいにけいさつかんがせんにゅうしたじけんで、だいがくのじちのはんいがあらそわれました。

それでは、いっしょにみていきましょう。

===== せくしょん1:けんぽう23じょうのほしょう =====

まず、けんぽう23じょうをかくにんしましょう。

「がくもんのじゆうは、これをほしょうする。」

とてもしんぷるなじょうぶんですね。でも、このみじかいじょうぶんには、ふかいいみがこめられています。

がくもんのじゆうには、3つのそくめんがあります。

1つめは、がくもんけんきゅうのじゆう。これがちゅうかくです。
しんりのたんきゅうをもくてきとするけんきゅうかつどうのじゆうです。
どんなてーまをえらぶか、どんなほうほうでけんきゅうするか、どんなけつろんをみちびくか、すべてじゆうです。

2つめは、けんきゅうはっぴょうのじゆう。
けんきゅうせいかをこうひょうするじゆうです。がっかいでのはっぴょう、ろんぶんのこうかん、めでぃあでのかいせつなど。
これは、ひょうげんのじゆう、つまりけんぽう21じょうともかさなります。

3つめは、きょうじゅのじゆう。
けんきゅうせいかをきょういくするじゆうです。おもにだいがくでのこうぎをそうていしています。
こうぎないようのせんたく、きょうかしょのせんてい、きょういくほうほうのけっていなどがふくまれます。

この3つをおぼえておいてください。けんきゅう、はっぴょう、きょういくのじゆうです。

さて、なぜけんぽうはがくもんのじゆうをめいぶんでほしょうしたのでしょうか。

それは、せんぜんのがくもんだんあつへのはんせいがあるからです。

せんぜんのにほんでは、せいふにひはんてきながくせつやしそうがだんあつされました。

ゆうめいなじけんを3つしょうかいします。

1933ねん、たきがわじけん。
きょうとだいがくのたきがわゆきとききょうじゅが、けいほうがくせつをりゆうにきゅうしょくしょぶんになりました。

1935ねん、てんのうきかんせつじけん。
みのべたつきちのけんぽうがくせつがこうげきされ、ちょしょがはっきんになりました。

1937ねん、やないはらじけん。
とうきょうだいがくのやないはらただおきょうじゅが、にっちゅうせんそうひはんでじしょくにおいこまれました。

このようながくもんだんあつへのはんせいから、せんごのにほんこくけんぽう23じょうで、がくもんのじゆうがめいぶんでほしょうされたのです。

がくもんのじゆうは、しんりのたんきゅうのため、ぶんかのはってんのため、そしてみんしゅしゅぎのきばんとして、とてもたいせつなけんりなんですね。

===== せくしょん2:だいがくのじち =====

つぎは、だいがくのじちについてです。

だいがくのじちとはなんでしょうか。

ていぎをいいます。

「だいがくにおけるがくもんけんきゅうときょういくのじゆうをほしょうするため、だいがくのないぶぎょうせいについて、だいがくのじしゅてきなけっていをみとめるせいど」

これがだいがくのじちです。

けんぽう23じょうのがくもんのじゆうから、せいどてきにほしょうされるとかいされています。

だいがくのじちのないようは、4つあります。

1つめ、じんじのじち。
きょういんのさいようやしょうしんなどを、だいがくがじしゅてきにけっていします。きょうじゅかいによるきょういんせんこうなどですね。

2つめ、しせつかんりのじち。
がくないしせつのかんり・うんえいを、だいがくがじしゅてきにおこないます。きゃんぱすないのちつじょいじなど。

3つめ、がくせいかんりのじち。
がくせいのにゅうがく・そつぎょうやちょうかいを、だいがくがけっていします。にゅうし、たんいにんてい、たいがくしょぶんなどです。

4つめ、よさんかんりのじち。
よさんのしとなどを、だいがくがじしゅてきにけっていします。けんきゅうひのはいぶんなどですね。

じんじ、しせつ、がくせい、よさん。この4つがだいがくのじちのないようです。

ただし、ちゅういしてください。

だいがくのじちは、むせいげんではありません。

だいがくのじちは、がくもんけんきゅう・きょういくにかんするじこうにげんていされます。

がくもんけんきゅう・きょういくとむかんけいなかつどうにはおよびません。

せいじかつどうなど、がくもんとかんけいないかつどうはほごされないのです。

だいがくのじちは、あくまで「がくもんのじゆうをほしょうするためのしゅだん」だということをおぼえておいてください。

===== せくしょん3:とうだいぽぽろじけん =====

それでは、もっともじゅうようなはんれい、とうだいぽぽろじけんをみていきましょう。

まず、じじつかんけいです。

1952ねん、とうきょうだいがくのがくせいげきだん「ぽぽろ」が、がくないでげきはっぴょうかいをかいさいしました。

このしゅうかいに、しふくけいさつかんすうめいが、がくせいにみぶんをいつわってにゅうじょうしました。

げきのとちゅうで、がくせいがけいさつかんのそんざいにきづきました。

がくせいたちはけいさつかんをとりかこんで、つるしあげました。

このこういが、ぼうりょくこういとうしょばつほういはんにあたるとして、がくせいらがきそされました。

べんごがわはしゅちょうしました。

「だいがくのじちにより、がくないのしゅうかいはけいさつけんりょくのかんしょうからほごされる。けいさつかんのせんにゅうはだいがくのじちへのしんがいだ。だから、がくせいのこういはせいとうぼうえいだ」

さて、さいこうさいはどうはんだんしたでしょうか。

さいこうさいは、こうはんじしました。

「だいがくのがくもんのじゆうとじちは、がくせいのしゅうかいにもおよぶ。しかし、そのしゅうかいがじっしゃかいのせいじてきしゃかいてきかつどうであり、こうかいのしゅうかいやこれにじゅんずるせいしつをゆうするものであるばあいには、だいがくのゆうするとくべつのがくもんのじゆうとじちはきょうゆうしない」

つまり、だいがくのじちはみとめない、というけつろんです。

なぜでしょうか。さいこうさいは3つのりゆうをあげました。

1つめ、しゅうかいのせいしつ。
ほんけんげきは「まつかわじけん」をだいざいとしていて、せいじてきしきさいがつよい。

2つめ、こうかいせい。
がくがいしゃのにゅうじょうもみとめられていて、じっしつてきにこうかいしゅうかいだった。

3つめ、がくもんせいのけつじょ。
しんにがくもんてきなけんきゅうやそのけっかのはっぴょうではなく、せいじてきしゃかいてきかつどうだった。

したがって、このしゅうかいはだいがくのじちのほごをうけません。

けいさつかんがせんにゅうしてもいほうではありません。

がくせいのぼうこうはせいとうかされません。

これが、とうだいぽぽろじけんのけつろんです。

ぽいんとをまとめますね。

だいがくのじちがおよぶのは、がくもんけんきゅう・きょういくかつどう、ないぶてきながくせいしゅうかい、がくじゅつてきなはっぴょうかいです。

だいがくのじちがおよばないのは、せいじてきしゃかいてきかつどう、こうかいしゅうかいまたはこれにじゅんずるもの、がくもんせいのないかつどうです。

おぼえかたをしょうかいします。

「ぽぽろはこうかいでせいじかつどう、がくもんじゃないからじちはむり」

ぽぽろ、こうかい、せいじかつどう、がくもんじゃない、じちはむり。

このふれーずでおぼえてください。

ちなみに、このぽぽろはんけつには、がくせつからひはんがあります。

おおくのがくせつは、ぽぽろはんけつがだいがくのじちをかどにせいげんしているとひはんしています。

がくせいによるじしゅてきなぶんかかつどう・せいじかつどうも、だいがくにおけるがくもんのじゆうのいっかんとしてほごされるべきだ。

「こうかいせい」のきじゅんがふめいかくだ。がくがいしゃをいちぶみとめただけで「こうかい」とするのはひろすぎる。

だいがくないへのけいさつのせんにゅうをあんいにみとめるべきではない。

このようなひはんがあることも、しっておいてください。

===== せくしょん4:はんれいまとめ =====

さいごに、がくもんのじゆうにかんするはんれいをまとめます。

1つめ、とうだいぽぽろじけん。しょうわ38ねん5がつ22にち、さいこうさいだいほうていはんけつ。
ろんてんは、だいがくのじちとがくせいしゅうかい。
けつろんは、せいじてきしゃかいてきかつどうでこうかいせいがあるしゅうかいにはだいがくのじちはおよばない。
きはんは、だいがくのじちはしんにがくもんてきなけんきゅう・きょういくかつどうにげんていされる。

2つめ、とやまだいがくたんいふにんていじけん。しょうわ52ねん3がつ15にち、さいこうさいだいほうていはんけつ。
ろんてんは、だいがくのたんいにんていけんげん。
けつろんは、だいがくにはたんいにんていのさいりょうがあるが、しいてき・せんだんてきはんだんはいほう。
きはんは、だいがくのじちとしてたんいにんていけんがあるが、むせいげんではない。

3つめ、あさひかわがくりょくてすとじけん。しょうわ51ねん5がつ21にち、さいこうさいだいほうていはんけつ。
ろんてんは、きょうしのきょういくのじゆう。
けつろんは、しょとうちゅうとうきょういくでは、きょうしのきょうじゅのじゆうはいっていのはんいでみとめられるが、だいがくほどひろくない。
きはんは、けんぽう23じょうのきょうじゅのじゆうは、おもにだいがくきょういくをそうていしている。

この3つのはんれいをしっかりおさえておいてください。

===== まとめ =====

それでは、だい10しょうのまとめです。

1. がくもんのじゆうには3つのそくめんがある。がくもんけんきゅうのじゆう、けんきゅうはっぴょうのじゆう、きょうじゅのじゆう。

2. だいがくのじちは、けんぽう23じょうからせいどてきにほしょうされる。ないようは、じんじ、しせつ、がくせい、よさんの4つのじち。

3. とうだいぽぽろじけんでは、せいじてきしゃかいてきかつどうでこうかいせいのあるしゅうかいには、だいがくのじちはおよばないとされた。

4. だいがくのじちは、がくもんけんきゅう・きょういくかつどうにげんていされる。せいじかつどうなどがくもんとかんけいないかつどうはほごされない。

がくもんのじゆうは、みんしゅしゅぎしゃかいのきばんです。

せんぜんのがくもんだんあつへのはんせいから、けんぽうでめいぶんでほしょうされました。

そして、がくもんのじゆうをじっこうてきにほしょうするために、だいがくのじちがみとめられています。

ただし、だいがくのじちはむせいげんではなく、しんにがくもんてきなかつどうにげんていされるということをわすれないでください。

だい10しょう、がくもんのじゆう、これでおわりです。

おつかれさまでした!

えんしゅうもんだいでちしきをかくにんしてくださいね。
